# lingxi-agent-api

Shared serializable protocol types for the Lingxi LLM client. This crate contains messages, requests, responses, provider profiles, settings, and related data types. It has no dependency on `lingxi-llm-client`.

See the [repository README](https://github.com/lingxi-coder/llm-client) and [API guide](https://github.com/lingxi-coder/llm-client/blob/main/docs/api.md) for examples.
